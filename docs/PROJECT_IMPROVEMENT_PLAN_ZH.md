# NUS 毕业设计项目改进计划

> 项目：基于异配性感知图神经网络的癌症驱动基因预测  
> 创建日期：2026-06-14  
> 用途：记录后续在研究可信度、实验验证、工程复现、论文质量和最终交付方面的改进路线。

## 1. 总体原则

现阶段不应继续盲目增加模型变体。应先统一代码实现、实验依据、论文表述和 GitHub 交付物，再考虑扩展研究范围。

> **2026-06-25 更新：** 在不使用显卡资源的前提下，已补齐 CPU 测试、复现文档、M5 现有结果统计汇总、环境文件和同配性分析脚本。
>
> **2026-06-25 范围决策：** 固定划分 GPU 重新验证、依赖本地缺失 HDF5 的直接同配性计算、Focal Loss/Label Smoothing 交互消融、最终 P7 模型上的 IG/GSEA 重跑，均从毕业交付的必做范围中移除。它们保留为可选未来工作。最终项目应使用现有结果，并明确标注其 legacy 证据属性。

工作顺序如下：

1. 修复研究完整性和实现口径问题。
2. 将核心实验结论收敛到现有证据能够支持的范围。
3. 将最终模型上的可解释性重跑保留为可选未来工作。
4. 提升代码仓库的可复现性。
5. 完成论文修订和最终完整性审计。

## 3. 第二阶段：可选鲁棒性重新验证

**预计时间：** 3-5 天，不包含服务器排队时间  
**优先级：** 当前范围下为可选未来工作

### 核心多随机种子实验

如果之后扩展项目范围，再使用完全相同的固定数据划分，至少运行五个随机种子：

- [ ] 六网络 baseline。
- [ ] 六网络 heterophily-aware 模型（P7）。
- [ ] 六网络 Cross-Network Attention 模型（P4）。

每个配置需要报告：

- 均值和标准差。
- 95% 置信区间。
- 每个随机种子的 AUPR 和 AUROC。
- 相对于 baseline 的配对效应量和统计检验结果。
- 训练时间和模型参数量。

### 异配性证据

- [ ] 计算每个 PPI 网络的整体标签同配性（label homophily）。
- [ ] 分别计算癌症基因和非癌症基因的类别同配性。
- [ ] 在适用情况下计算标签 assortativity。
- [ ] 分析 P7 的性能提升是否与网络异配性程度相关。
- [ ] 在论文中增加表格或图形，直接展示支持核心假设的结构证据。

### 可选消融实验

- [ ] 运行 Focal Loss 和 Label Smoothing 的 2x2 消融：
  - 两者均不使用。
  - 仅使用 Label Smoothing。
  - 仅使用 Focal Loss。
  - 同时使用两者。
- [ ] 使用多个随机种子重新进行增益分解：
  - 单网络 benchmark。
  - 六网络 benchmark。
  - 六网络 improved baseline。
  - 六网络 heterophily-aware 模型。
- [ ] 当 CPDB 是测试网络时，对比 CPDB 作为输入网络和不作为输入网络的结果。
- [ ] 明确区分标准 transductive protocol 和更严格的 leave-target-network-out protocol。

### 当前最终范围下的论文主张原则

原计划建议将论文核心结论收敛为：

> 在固定数据划分和多个随机种子下，heterophily-aware gating 相对于结构相同的六网络基线，能够稳定提高癌症驱动基因预测性能。

在当前最终范围下，应使用更窄的结论：现有 legacy 三随机种子 M5 结果显示 P7 是已评估扩展中最强的六网络基线改进，固定划分重新验证留作未来工作。除非能够在完全相同的数据集和划分上复现近期竞争方法，否则不应声称达到当前最优性能。

### 阶段完成标准

- P7 核心结果至少由五组配对实验支持。
- 项目数据集上的异配性得到直接测量，而不是只引用其他论文。
- Focal Loss 性能下降的解释得到消融实验验证。
- 数据增益和架构增益在一致协议下得到分离。

## 4. 第三阶段：可选可解释性扩展

**预计时间：** 1-2 天  
**优先级：** 当前范围下为可选未来工作

### 任务

- [ ] 在最终验证后的 P7 模型上运行 Integrated Gradients。
- [ ] 使用同一个最终模型的预测运行 Enrichr ORA 和 pre-ranked GSEA。
- [ ] 对比至少两种 IG baseline：
  - 零向量 baseline。
  - 特征均值 baseline。
- [ ] 生成 4x16 多组学特征重要性热力图。
- [ ] 生成 PPI 网络权重图或 gene-level attention 图。
- [ ] 准备以下基因的完整案例分析：
  - TP53。
  - PIK3CA 或 CTNNB1。
  - 一个具有合理生物学依据的新预测癌症基因。
- [ ] 明确讨论 hub gene 和基因长度混杂问题，包括 TTN、UBC 等基因。
- [ ] 仅在最终模型和数据流程稳定后继续修复 GNNExplainer。

### 阶段完成标准

- 预测结果和可解释性结果来自同一个最终模型系列。
- 特征归因结论不依赖单一 baseline。
- 生物学解释同时包含支持证据和潜在混杂风险。

## 7. 暂缓工作

以下工作不应阻塞毕业交付。只有在核心阶段提前完成后才考虑继续：

- P1 Random-Walk Positional Encoding 优化。
- P3 使用线性注意力或轻量注意力替代 GPS。
- P5 需要 MSigDB 数据的 pathway hypergraph 实验。
- P6 需要谱预处理的 HIPGNN 实验。
- P8 PINNACLE embedding 实验。
- P10 GNNExplainer 调试。
- 大规模组合多个 M5 技术。

这些扩展会增加项目范围，但不能解决当前最重要的研究可信度和可复现性问题。
